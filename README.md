# Random Wallpaper Changer for Windows

A lightweight Windows application that automatically changes your desktop wallpaper every time Windows starts.

The program allows you to select a folder containing your wallpapers, then each time the system starts, it randomly chooses a new wallpaper **without repeating any previously used image** until all wallpapers in the folder have been used once. After completing the full cycle, the process starts over again.

## Features

* Automatically runs on Windows startup
* Randomly selects a wallpaper from your chosen folder
* Prevents repeating wallpapers until all images are used
* Simple GUI for selecting the wallpaper folder
* Lightweight and easy to use

## How to Use

1. Download and extract the project files
2. Run `gui.exe`
3. Select the folder containing your wallpapers
4. Click **Enable**
5. Every time Windows starts, a new random wallpaper will be applied automatically
